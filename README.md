| Vista | URL | Uso |
| :--- | :--- | :--- |
| **Mixto** (por defecto) | [/online-cv/](https://daniquir.github.io/online-cv/) | Equilibrio impacto + stack |

El botón PDF descarga el PDF de la vista activa. Tests del modelo: `npm test` (o `ruby scripts/test-cv-views.rb`).
